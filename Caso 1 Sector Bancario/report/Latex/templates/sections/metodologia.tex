\chapter{Metodología}

El presente estudio fue desarrollado siguiendo un flujo de trabajo estructurado orientado a garantizar la calidad de los datos y la correcta documentación del proceso de análisis. La metodología integra herramientas para la preparación, exploración, análisis y presentación de resultados, permitiendo obtener un informe técnico reproducible.

\section{Herramientas utilizadas}

Durante el desarrollo del análisis se emplearon las siguientes herramientas:

\begin{itemize}

\item MySQL para la limpieza, transformación y preparación del conjunto de datos.

\item Python como lenguaje principal para el análisis de datos.

\item Pandas y NumPy para el procesamiento y manipulación de la información.

\item Bokeh para la elaboración de visualizaciones.

\item Jupyter Notebook para el desarrollo del análisis.

\item \LaTeX{} para la generación del informe técnico final.

\end{itemize}

\section{Flujo metodológico}

El proceso de trabajo se desarrolló mediante las siguientes etapas:

\begin{enumerate}

\item Obtención del conjunto de datos.

\item Evaluación inicial mediante un análisis exploratorio (EDA) para conocer el estado de la información.

\item Limpieza, transformación y preparación de los datos utilizando MySQL.

\item Exportación del conjunto de datos preparado.

\item Validación del conjunto de datos mediante un segundo análisis exploratorio.

\item Desarrollo del análisis para responder las preguntas planteadas.

\item Generación automática de tablas, figuras y textos empleados en el informe.

\item Elaboración del informe técnico en \LaTeX.

\end{enumerate}
