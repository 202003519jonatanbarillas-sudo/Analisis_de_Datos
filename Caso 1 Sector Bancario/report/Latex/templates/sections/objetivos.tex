\section*{Objetivos Específicos}

\begin{itemize}

\item Evaluar la calidad y consistencia del conjunto de datos mediante la identificación de valores faltantes, registros duplicados y posibles inconsistencias.

\item Analizar el comportamiento de las variables de interés utilizando estadísticas descriptivas y visualizaciones.

\item Identificar patrones, tendencias y relaciones relevantes entre las variables analizadas.

\item Responder las preguntas planteadas mediante técnicas de análisis de datos.

\item Documentar los principales hallazgos, conclusiones y recomendaciones derivados del estudio.

\end{itemize}
