\section{Propósito del informe}

El presente documento tiene como finalidad presentar de forma estructurada el proceso de análisis desarrollado sobre el conjunto de datos seleccionado. El informe documenta las etapas de preparación de los datos, la metodología aplicada, los resultados obtenidos para responder las preguntas de análisis y las principales conclusiones y recomendaciones derivadas del estudio.

\section{Estructura del informe}

El informe se organiza en los siguientes capítulos:

\begin{itemize}

\item Descripción del conjunto de datos.

\item Metodología utilizada durante el análisis.

\item Preparación y transformación de los datos.

\item Resultados del análisis organizados por cada una de las preguntas planteadas.

\item Principales hallazgos.

\item Conclusiones.

\item Recomendaciones.

\item Anexos con información complementaria.

\end{itemize}
