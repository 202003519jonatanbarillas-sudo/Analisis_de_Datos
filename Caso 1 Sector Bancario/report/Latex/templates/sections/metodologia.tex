\chapter{Metodología}

El análisis exploratorio de datos fue desarrollado utilizando Python como lenguaje principal de programación.

Para el procesamiento de los datos se empleó la biblioteca Pandas, mientras que NumPy fue utilizada para operaciones numéricas.

Las visualizaciones fueron elaboradas mediante Bokeh con el objetivo de obtener gráficos interactivos y de alta calidad.

Durante el proceso se realizaron las siguientes etapas:

\begin{enumerate}
\item Carga del conjunto de datos.
\item Exploración inicial.
\item Identificación de valores faltantes.
\item Detección de registros duplicados.
\item Conversión de tipos de datos.
\item Estadísticas descriptivas.
\item Análisis univariado.
\item Análisis bivariado.
\item Elaboración de visualizaciones.
\item Interpretación de resultados.
\end{enumerate}
